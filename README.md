# Clover Kingdom Revolution

GitHub Pages-ready export of the current Clover Kingdom Revolution archive preview.

## Important
This package is a **static production snapshot** of the preview you uploaded. It does not contain the original React source tree (`App.js`, `package.json`, backend, etc.) because the uploaded preview ZIP contains the compiled browser bundle.

The Emergent-hosted logo dependency has been replaced with the local `logo.png`.

## Publish on GitHub Pages
1. Create a public repository named `clover-kingdom-revolution`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

No build step is required for this snapshot.
